02 / ANALYTICAL TOOLKIT

Choose the right analysis

Separate deterministic counts from model interpretations and marketing hypotheses.

Feature plan
EXPLORE / PLANNED

Find the record, then trace its context.

Search original Chinese text by exact term, keyword or tag; add semantic retrieval only after a benchmark. Follow a commenter to their captured profile and thread history when identity is resolved. Inspect source order, creator replies, retained media and capture gaps.

Exact + tag searchTerminologyCommenter traceThread path
ARCHIVED SOURCE Pinned local recordLIVE SOURCE External locator · availability unknown
Output citable source selectors and separate archived/live links
TERMINOLOGY / PLANNED

Keep the original phrase in view.

Pair exact Chinese wording and alternate spellings with reviewed contextual readings, example threads, counterexamples and uncertainty. A translation correction makes a new revision; it never replaces the captured text.

Original wordingAlternate formExample threadRevision
Output source-linked term notes
DETERMINISTIC QUERIES / PLANNED

Reproduce every number.

Save query version, snapshot set, filters, numerator, denominator, distinct-count dimension, missingness and timestamp. Keep counts of comments, accounts, posts and creators separate.

SQL / FTSQuery versionDenominatorMissingness
Output auditable measurements
DISCOVER / PROPOSED

Find something worth testing next.

Generate candidate patterns or unexpected combinations with source examples and counterexamples. Record the comparison to test, then evaluate it on a distinct held-out selection. A discovery suggestion does not become a finding automatically.

Candidate patternCounterexampleHeld-out testUncertainty
Output testable research questions
MARKETING STUDY / PROPOSED

Compare response without inflating intent.

Compare captured themes, formats, engagement patterns and creator responses within a named study. Keep admiration, shopping inquiry and reported purchase as separate categories. Show sample size and time window; a captured collection is not the wider audience.

AdmirationShopping inquiryReported purchaseCreator replies
Output qualified market hypotheses
AI-ASSISTED ANALYSIS / UPGRADE NEEDED

Interpret with a recorded session.

Provide bounded, cited source selections to ChatGPT or Gemini only after a capability and transport check. Preserve model/provider revision, prompt version, omissions, receipts and uncertainty. Model output becomes a proposed observation, not a verified finding.

Provider checkPrompt revisionCitationsReview queue
Output reviewable observations
REVIEW / PLANNED

Make disagreement visible.

Review support and counterexamples with exact source selectors, translation corrections, model disagreements, uncertainty and capture gaps. Approvals move findings through proposed, reviewed, rejected and superseded states; source evidence stays untouched.
